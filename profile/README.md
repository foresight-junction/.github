# Foresight · ED-72

How well can an AI agent run an emergency department for 72 simulated hours? Every 30 minutes, it decides which patients get beds, where staff work, and when staff can take a break. It has to keep up with changing demand and make those decisions within a fixed budget.

We built ED-72 for AfterQuery’s **Break the Agent** challenge at Junction 2026. All patients, staff, and events are synthetic.
